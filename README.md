# Лабораторная работа №2 - Циклы с предусловием и постусловием.

Выполнил: Горбунов Роман Андреевич
Вариант: 4

Данная работа включает в себя выполнение двух частей задачи с помощью предусловия (while) и постусловия (do while).
В программу нужно ввести необходимые переменные (они указаны в комментарии перед вводом данных), а после программа посчитает и выдаст ответ в виде таблицы.
